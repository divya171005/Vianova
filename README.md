# ViaNova – Explore the World 🌍

A responsive travel website built using HTML5 and CSS3, designed to inspire travellers to discover beautiful destinations and explore exciting travel experiences.

## ✨ Features

- Elegant and responsive navigation bar
- Hero section with a full-width background image
- Destination cards showcasing popular places around the world
- Travel packages section
- Why ViaNova section highlighting key features
- Call-to-action section
- Traveller testimonials
- Responsive layout for mobile, tablet and desktop screens
- Smooth scrolling and interactive hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## 🚀 Getting Started

1. Clone this repository:

   `git clone https://github.com/divya171005/Vianova.git`

2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

ViaNova is designed to adapt to different screen sizes, including desktops, tablets and mobile devices.
